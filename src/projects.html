01Full-stack · Healthcare

Nena na Daktari

A consultation assistant for doctors: it captures consultation audio, structures the clinical history, and provides evidence-backed medical suggestions. The system is split into a Django REST API and a React TypeScript client.

Open live app Repository
Engineering notes
  • Modular Django apps for accounts, patients, encounters, and shared core utilities.
  • REST endpoints consumed by a typed React client with a dedicated API service layer.
  • PostgreSQL in production, with SQLite retained for a zero-setup local environment.
  • Docker Compose for local development and GitHub Actions for CI/CD.

02Django · E-commerce

Sweet Crumbs

A bakery e-commerce application built with Django 5: a categorized product catalog, session-based shopping cart and checkout, order lifecycle tracking, and email-based customer accounts.

The codebase is organised by domain rather than by file type — products, orders, accounts, and core site concerns each own their models, views, templates, and admin configuration.

Repository
Engineering notes
  • Order and order-item models covering the full order lifecycle.
  • Session-based cart with checkout, then order tracking for customers.
  • Email-based authentication through django-allauth.
  • SQLite in development with a PostgreSQL-ready production configuration and Whitenoise static file serving.
  • Optional AI chat assistant integration kept behind configuration.
Stack
  • Python
  • Django 5
  • django-allauth
  • PostgreSQL
  • Tailwind CSS
03Django Ninja · React

Workflow Tracker

An internal operations tool that moves applications through defined workflow states — draft, submitted, under review, needs more information, approved, or rejected — with reviewer actions and draft/edit restrictions.

Repository
Engineering notes
  • Workflow rules kept on the backend, so status changes cannot bypass validation from the UI.
  • Typed request and response schemas with Django Ninja, plus a service layer for transitions.
  • React, Vite, and Tailwind front end with separate API, hooks, and page modules.
  • Draft and edit restrictions driven by the current application state.
Stack
  • Python

  • React
  • TypeScript
  • SQLite
04API integration · Clinical

CarePoint

A patient-management application built for a software engineering practical assessment. It implements patient registration, vital-sign recording with automatic BMI calculation, overweight and general assessments, and a searchable patient directory.

The front end integrates with a supplied patient-visit REST API, including authentication, token handling, and documented API constraints discovered during implementation.

Repository
Engineering notes
  • Authenticated clinical routes with unauthenticated users redirected to sign-in.
  • Form validation with React Hook Form and Zod schemas before API submission.
  • Explicit loading, empty, error, and not-found states, plus an error boundary.
  • BMI calculation and category display derived from recorded height and weight.
  • Third-party API integration, including documented request and response constraints.
Stack
  • React
  • TypeScript
  • Vite
  • React Router
  • Zod
  • Tailwind CSS
